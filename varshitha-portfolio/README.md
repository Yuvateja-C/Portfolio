# Varshitha Kothakota — AI Product Manager Portfolio

A premium, production-ready portfolio website positioned for AI Product Management roles.

## Overview

This portfolio showcases Varshitha Kothakota's experience as an AI-first product builder, featuring:

- **Founder experience** with Glyphora (live real estate marketplace)
- **AI research** at DST-CURIE-AI Centre, SPMVV Tirupati
- **4 Google Cloud GenAI certifications**
- **Product case studies** with PM-framework analysis
- **7+ professional roles** across product, data, AI, and growth

## Tech Stack

- **HTML5** — Semantic, accessible structure
- **CSS3** — Custom design system with CSS variables, glassmorphism, gradients
- **Vanilla JavaScript** — No framework dependencies
- **GSAP 3.12** + ScrollTrigger — Scroll-based animations
- **Lenis** — Smooth scroll
- **SplitType** — Text split animations
- **Typed.js** — Typing effect in hero
- **AOS** — Animate on Scroll

## Design Inspiration

Visual system inspired by Apple, Linear, Stripe, Vercel, and Raycast.

## Local Development

Open `index.html` directly in a browser, or serve locally:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

Then visit `http://localhost:8000`.
