# C Yuva Teja — Generative AI Engineer Portfolio

A production single-page portfolio built with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**, highlighting Generative AI engineering, LLM architectures, RAG systems, and AI microservices.

## 🚀 Professional Identity

**Generative AI Engineer** specializing in:
- Large Language Models (LLMs) & Prompt Engineering
- Retrieval-Augmented Generation (RAG) & Vector Search (ChromaDB / FAISS)
- Autonomous AI Agents & Intelligent Workflow Automation
- FastAPI, Python, & Cloud-Native AI Microservices

## 🛠️ Local Development & Build

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build production bundle
npm run build

# Start production server
npm run start
```
